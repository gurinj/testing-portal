## What M0 found

1. **SaxonJS browser build** could not be downloaded in the build environment (only npm and GitHub are reachable). The Node build `SaxonJS2N.js` runs unchanged in a worker with small stand-ins for Node features. It is the same engine as in the Node tests.
2. **IBAN check in XPath is wrong in SaxonJS** for long numbers (precision). The sample rule reported every valid IBAN as wrong. Fixed with a JavaScript function, as ADR-002 already suggested.
3. **Rule patterns can be quadratic.** Duplicate counting with `//` and a parent condition in a rule context made 10,000 transactions take minutes. With keys and simple contexts: 4.5 s. Written down as mandatory rules in `docs/RULES.md`.
4. **Offline file:** a module worker does not start from a `blob:` URL on a page opened from disk. The build turns the XSD worker into a classic worker for the offline file.
5. **Claude artifact downloads** accept csv, txt, json, html, zip and some others, **not xml**. The corrected file in M3 needs another route there (zip or copy). Printing is not allowed in the artifact.
6. **Runtime compilation** of rule files in the browser works (about 1.5 s per file). An option for later: change rule files without a build.
