# M1 – First working version

**Status:** Done, for review · 2026-11-17
**Plan:** `claude/testing-portal-static-app-plan.md`, sections 5 and 6. Delivery: offline file only (decided 2026-11-17).

## Goal

A service desk user opens the offline file, chooses a pain.001 file and a country, and gets a report with all findings of stages 0–2 and of the 20 sample rules, in the prototype design.

## Scope

1. **Stages 0–2 with catalogue ids.** 0.1, 0.2, 0.3, 0.5, 0.7, 0.8, 0.9; 1.1–1.4; 2.1–2.11 (libxml2 messages classified). Not possible or needing CMIplus input: 0.4, 0.6, 0.10, 1.5, 1.6 (listed in `config/catalogue.json`).
2. **Sample rules in stage files** that cover `.03` and `.09`: `rules/stages/04-iso-business-rules.sch`, `05-characters-and-formats.sch`, `07-payment-types.sch`, `09-consistency.sch`, `10-warnings-and-hints.sch`. The build compiles one variant per version.
3. **Findings:** catalogue title, check and hint (`config/catalogue.json`); where (file, block n, transaction m with EndToEndId); actual value; line and column; repeated findings grouped; a rule finding on an element that already failed the XSD is suppressed and counted on the XSD finding.
4. **Status** per file, block and transaction (RJCT, ACWC, ACTC). PART is not used until a country accepts files partly.
5. **Screens:** start (file, detected format, country), run with real progress per module, report (status, facts, module strip, severity filter, search, expand all, findings by level, locations, payment blocks and transactions), XML viewer (line markers, step through findings, large files), CSV export, printable report (HTML file), About (version, limits, third-party notices, technical check).
6. **Header line:** Temporary tool · version · rules as of · draft rules.

## Not in M1

Stage 3 payment-type derivation and all other catalogue rules (M2), country packs (M2), Fix the errors, run comparison, email (M3).

**Found and fixed during M1:**
- libxml2 stops checking an element after a child that is out of place, repeated or unknown, so later errors in it were missing. The XSD worker now removes such children and checks again.
- XSD paths failed for files that use a namespace prefix (`<p:Document xmlns:p=…>`): the lookup now ignores prefixes.
- A choice with no option was reported as 2.2; it is now 2.5, recognised by the options libxml2 lists.

**Independent review:** a separate agent checked rules, stages and report against the catalogue and found 17 points (16 confirmed by running). All are fixed except the partial checks of 4.2, 7.6 and 5.6, which M2 completes (`docs/LIMITS.md`). Each fix has a test.
